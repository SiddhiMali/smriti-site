The problem

On STALE, a research benchmark built around changes like these, popular memory systems catch about 10% of them.

On the same conversation, Mem0 kept both the old fact and the new one as current.

What Smriti does

  1. Checks a memory right before an action.

    Just before your agent acts on something it remembers about a user, Smriti checks that it still holds, including changes the user never stated outright.

  2. Shows the message that changed it.

    When a memory no longer holds, you see the message where it changed, not just a verdict.

  3. Works alongside the memory system you already use.

    Mem0, Zep and Letta keep storing memories as they do now. Smriti adds the check.

Fraud detection checks a payment before it goes through. Smriti checks a memory before an agent acts on it.
